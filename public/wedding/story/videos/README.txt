Background films go here, named to match the paintings:

  dream-1.mp4
  dream-2.mp4
  dream-3.mp4

Each one loops behind the site wherever its painting is used. The matching
painting in ../bg/ stays underneath as the poster frame, so if a film is
missing or slow the page still looks right.

Keep each file under about 4MB — three autoplaying loops is real data on a
phone. H.264 (MP4), muted, no audio track needed.
